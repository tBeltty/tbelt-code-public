Privacy

tBelt Code does not ask for personal data, has no accounts and sends no telemetry. This page lists what the website and the app do with data.

Website

tbelt.online has no forms, sign-in, cookies of its own, analytics or trackers. The page asks /api/releases for the latest version number and shows it next to the download buttons.

The site is hosted on Cloudflare Pages. Cloudflare keeps the technical logs a web host normally keeps, such as the IP address and the requested page, to serve the site and protect it from abuse.

The page loads the Roboto fonts from Google Fonts, so Google receives the visitor's IP address with that request.

Downloads

The installers are served from bucket.tbelt.online, a Cloudflare R2 bucket. It keeps the same technical logs as the website.

The app

tBelt Code sends no telemetry or usage analytics and uploads no sessions. Sessions are saved on your computer.

Your messages and the code a session reads go to the model provider you configure, under that provider's terms. No provider is configured until you add one.

The app checks tbelt.online for new versions. That request carries no account or session data.

Contact

Questions about privacy: open an issue in the public repository.
